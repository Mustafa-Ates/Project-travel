# Project-travel
Users can filter travel destinations by country or city, add them to their favorites, and view descriptions and photos for each location.

## Features

- Live search
- Category filtering
- Favorites system with a dedicated filter, saved persistently using localStorage
- Real-time weather display
- 10-year historical weather average for selected dates
- Photo modal with a 4-image slider

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6 Modules)
- Unsplash API
- Open-Meteo API (Geocoding, Forecast & Archive)
- localStorage

## How to Run

1. Clone or download this repository
2. Rename `config.example.js` to `config.js`
3. Get a free API key from [Unsplash Developers](https://unsplash.com/developers) and add it inside `config.js`
4. Open `indeks.html` in your browser
